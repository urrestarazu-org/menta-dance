Accesibilidad

Queremos que cualquier persona pueda usar el sitio de Menta Dance. Esta página cuenta qué hacemos para lograrlo y cómo avisarnos si algo no funciona.

1. Qué tenemos en cuenta

  • Un enlace para saltar directo al contenido principal al navegar con teclado.
  • Una estructura de títulos ordenada y secciones identificadas, para lectores de pantalla.
  • Formularios con etiquetas asociadas a cada campo y mensajes de error que se anuncian.
  • Un menú móvil que funciona sin JavaScript y se maneja con teclado.
  • Texto que se adapta al tamaño de la pantalla y al zoom del navegador.

2. Nuestro compromiso

Tomamos como referencia las pautas WCAG 2.1 nivel AA. Todavía no hicimos una auditoría completa, así que puede haber partes del sitio que no las cumplan.

3. Cómo avisarnos

Si encontrás una barrera de accesibilidad, o necesitás un contenido en otro formato, escribinos desde la página de contacto contándonos qué página y qué dispositivo o ayuda técnica usás. Vamos a responderte y a buscar una alternativa.

4. Clases presenciales

Si necesitás algún ajuste para participar de una clase presencial, consultanos antes de reservarla y lo coordinamos con el equipo.
