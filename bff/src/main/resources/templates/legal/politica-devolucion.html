Política de devolución

Cómo pedir la cancelación de una compra y el reembolso del dinero.

1. Derecho de revocación

Las compras hechas a distancia pueden revocarse dentro de los diez días corridos contados desde la contratación, según el artículo 34 de la Ley 24.240 de Defensa del Consumidor, siempre que el servicio no se haya usado de forma sustancial. Para ejercerlo escribinos desde la página de contacto indicando el email de tu cuenta y la compra.

2. Planes de suscripción

  • Si pediste la revocación dentro del plazo y todavía no usaste el contenido, se reintegra el importe completo.
  • Pasado el plazo, o una vez usado el contenido, no se reintegra el período ya habilitado.

3. Clases presenciales

  • Si cancelás con anticipación suficiente para que el cupo se libere, se reintegra la sesión.
  • Si Menta Dance cancela o reprograma una clase, se reintegra la sesión o se ofrece otra fecha.
  • Las sesiones a las que no asistís sin avisar no se reintegran.

4. Pagos rechazados o duplicados

Si un pago fue rechazado, no se te cobra. Si por un error se cobró dos veces, el excedente se devuelve por el mismo medio de pago.

5. Cómo se devuelve el dinero

El reembolso se hace por el mismo medio con el que pagaste. Los plazos de acreditación dependen de Mercado Pago o del banco.
